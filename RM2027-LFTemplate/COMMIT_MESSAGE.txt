refactor(lfcore)!: 迁移 C++ 模块并统一矩阵与力控计算

将 LFCore 的 8 个 C 源文件迁移至 C++，统一文件名和函数命名，
让 Kalman、四元数 EKF 与 Force 复用矩阵接口，减少控制周期内的重复工作。

- 引入 SJTU 矩阵/向量模块并保留署名与 MIT 许可证
- 提供固定尺寸 Matrix 和借用数组的 View，修复复制后的数据绑定与矩阵范数
- 为 1～4 列矩阵向量乘法增加展开内核，其他尺寸复用 CMSIS-DSP
- 去除矩阵复制及完全覆盖结果的重复清零，保留默认构造的零矩阵语义
- Kalman 集中管理工作缓冲，支持测量维度大于状态维度，并保留首个运算错误
- EKF 修复卡方残差转置和增益缩放覆盖，复用平方范数并减少求根、除法与 acosf
- Force 复用紧凑矩阵向量乘法，缓存惯量/周期、滤波权重和电机换算系数
- 合并 BMI088 SPI 事务、遥控器协议与双 DMA 缓冲处理，修复重试状态及缓存行隔离
- 修复 INS 任务及 HAL 回调的 C 链接，避免落入默认弱实现
- LFCore 默认启用 -O3，增加独立 performance 构建和默认关闭的 DWT 周期统计
- 函数统一为小驼峰，同步 clang-tidy 与团队规范；使用 SJTU 规则替换工程 .clang-format
- 更新根 README，说明 RM2027-LFTemplate 的分层、模块接口及构建用法

验证：
- 默认、performance 和 DWT 统计构建通过，生成 ELF/HEX/BIN
- 30,244 项矩阵、Force、Kalman/EKF 与 LPF 数值检查通过
- 四种遥控器协议、DMA 流程与 DWT 计时器回归通过
- 核验 INS/中断入口符号与关闭统计时的代码裁剪

性能构建的 text 相较优化前增加约 5%；尚未进行板上延时实测，
不据主机回归结果或代码体积宣称加速倍数。

BREAKING CHANGE: LFCore C++ 接口使用 .hpp，函数名统一为小驼峰；
调用方需同步头文件与接口名。仅用于旧阈值判断的 gyro_inv_norm 字段已移除。
