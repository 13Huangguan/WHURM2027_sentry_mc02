# 打滑负载重分配

> 当前状态：仅提供独立算法接口，尚未接入 `ChassisController`，
> 不会影响现有底盘控制、CAN 电流或功率管理。

本模块把 2025 哨兵技术报告中的打滑力分配思想接入当前四全向轮底盘：

1. 通过实际轮速和目标轮速计算逐轮速度比；
2. 正常打滑时选择相对轮速最低的轮子增载；
3. 异常高速打滑时把对应轮子的命令向零减小；
4. 通过基础分配矩阵的零空间完成调整，不改变整车 `[Fx, Fy, Mz]`；
5. 保持每个轮子原有输出方向，并限制零空间系数变化率。

## 输入输出

模块输入为：

- `ForceSolver` 计算出的基础四轮电流；
- 电机反馈轮速；
- 由底盘目标速度计算出的四轮目标轮速；
- 运动估计器给出的打滑位图和置信度；
- C620 电流上限。

输出为重分配后的四轮目标电流，之后继续进入功率控制。

后续接入时，应在 `ForceSolver` 之后、功率控制之前调用本模块，不应把算法
细节写回 `ForceSolver` 或 CAN 发送流程。

## 零空间调整

当前四全向力的一个零空间方向为：

```text
k = [-1, +1, -1, +1]
```

模块对它归一化后计算：

```text
I = I0 + alpha * ||I0|| * k
```

因此：

```text
A * I = A * I0
```

整车的 `Fx、Fy、Mz` 保持不变。

## 正常打滑

当最高轮速比超过 `normal_ratio_enter`，且最高与最低轮速比之差超过
`normal_ratio_spread` 时：

- 选择相对速度最低且置信度满足要求的轮子；
- 沿该轮原有输出方向增加驱动力；
- 其余轮子通过零空间自动减载；
- 不允许任何轮子的输出方向翻转。

## 异常打滑

当某个轮速比超过 `abnormal_ratio_enter`，并与最低轮速比拉开足够差距时：

- 优先选择该异常轮；
- 沿零空间把它的目标电流向零移动；
- 如果电流或方向约束导致不能完全归零，状态标记为 `Limited`。

## 调试参数

主要参数位于 `chassis_config.hpp`。首次实车调试建议：

1. 先关闭 `kEnableSlipRedistribution`，记录目标轮速、实际轮速和轮速比；
2. 根据日志调整正常、异常阈值；
3. 从较小的 `kSlipMaxAdjustmentFraction` 和变化率开始；
4. 分别验证单轮悬空、单侧低附着和上坡工况；
5. 确认所有轮子的输出方向不会在调整过程中翻转。

当前默认参数只是安全起点，不是实车标定结果。
